# Magic Link website

Minimal bilingual product and purchase website for Magic Link.

- `/` — global English page
- `/zh-cn` — Simplified Chinese page
- `NEXT_PUBLIC_DOWNLOAD_URL` — latest signed installer or GitHub Release
- `NEXT_PUBLIC_PADDLE_CHECKOUT_URL` — Paddle checkout URL

```bash
npm install
npm run dev
npm run build
```

The website contains no application source code, license private keys, or activation tools.
